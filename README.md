# 🚀 Explore Azure Databricks

This project was created to explore the basic features of **Azure Databricks**, a fast, easy, and collaborative Apache Spark-based analytics platform optimized for Microsoft Azure.


## 🎯 Purpose

- Learn how to provision an Azure Databricks workspace
- Understand how to create and manage Spark clusters
- Explore data analysis using Databricks notebooks
- Visualize data and apply basic filtering techniques


## 🧭 Steps Followed

1. **Signed in to Azure Portal**  
   Accessed the Azure portal and began the setup process for Databricks.

2. **Created a Databricks Workspace**  
   A new resource group and Databricks workspace were created in the Azure environment.

3. **Launched the Workspace & Created a Cluster**  
   A single-node cluster was configured to minimize resource usage during testing.

4. **Uploaded Sample Data**  
   A sample dataset (`products.csv`) was uploaded using the Databricks data upload interface.

5. **Created a Table from CSV File**  
   The CSV file was converted into a table under the default `hive_metastore` catalog.

6. **Viewed and Visualized Data**  
   Used SQL queries to retrieve data and built a bar chart showing product count by category.

7. **Filtered Data**  
   Retrieved only the data related to "Road Bikes" using simple filtering logic.

8. **Cleaned Up Resources**  
   Terminated the cluster and deleted unnecessary resources to avoid additional costs.



## 🧩 Use Cases

Azure Databricks can be applied in a variety of real-world scenarios:

- **Big Data Processing**: Efficient handling and transformation of massive datasets
- **Data Science & Machine Learning**: Model training, evaluation, and deployment
- **Real-time Analytics**: Processing and analyzing streaming data
- **Business Intelligence**: Combining and analyzing data for strategic decision-making



## 📘 What I Learned

- Gained hands-on experience with Databricks on the Azure platform
- Understood how clusters, workspaces, and notebooks interact
- Learned to load and explore data using the Databricks UI
- Created visualizations to make insights more accessible
- Practiced managing cloud resources effectively
